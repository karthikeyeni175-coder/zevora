# ZEVORA Beauty — React (Vite)

Converted from the original HTML/CSS/JS project. Same markup, same CSS, same JS behaviour.

## Run

```bash
npm install
npm run dev
```

## Structure

- `index.html` — original <head> (fonts, Font Awesome) + React root
- `public/` — all images + `main.css` (the original CSS, unmodified)
- `src/components/` — original HTML sections converted to JSX
- `src/salon.js` — original JavaScript, run once after mount
- `src/App.jsx`, `src/main.jsx`
